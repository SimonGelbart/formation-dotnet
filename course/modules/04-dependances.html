Faire collaborer les objets

Objectif : remplacer l'origine du catalogue sans modifier le service qui l'utilise.

Pratiquer · interface, injection constructeurComprendre · composition, polymorphisme

Le service reçoit son collaborateur

public class CatalogService
{
    private readonly IProductCatalog _catalog;
    public CatalogService(IProductCatalog catalog) => _catalog = catalog;
    public int Count() => _catalog.GetAll().Count;
}

Le service dépend d'un contrat. MemoryCatalog et EmptyCatalog peuvent fournir des comportements différents derrière la même interface.

DI ≠ absence de new

La construction a toujours lieu quelque part. L'intérêt est de sortir le choix du collaborateur du service qui l'utilise.
