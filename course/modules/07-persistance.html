Chapitre 07 · Backend

Conserver les produits avec SQLite

Objectif : retrouver un produit après l'arrêt puis le redémarrage de l'API.

Pratiquer · migration, lecture, sauvegardeComprendre · tracking, IQueryable, NuGet

La frontière de sauvegarde

_db.Products.Add(product);
await _db.SaveChangesAsync(cancellationToken);

Add fait suivre l'entité. SaveChangesAsync envoie effectivement les changements vers SQLite.

LINQ devient SQL

var query = _db.Products
    .Where(p => p.Name.StartsWith("C"))
    .OrderBy(p => p.Name);
var products = await query.ToListAsync(cancellationToken);

Tant que la requête reste un IQueryable, EF peut la traduire. ToListAsync déclenche l'exécution.

Expérience de sauvegarde

Commente temporairement SaveChangesAsync, fais un PUT/POST puis relis avec une nouvelle requête : l'ancien état réapparaît.
