Chapitre 11 · Bilan

Réaliser une évolution seul

Défi final : ajouter une description facultative au produit, persistée, exposée en HTTP et couverte par un test.

Critères de réussite

  1. L'ancien POST sans description fonctionne encore.
  2. POST et PUT acceptent la description ; GET la renvoie.
  3. La donnée survit à un redémarrage.
  4. Un test vérifie l'évolution.
  5. Les tests existants restent verts.
PratiquerModifier endpoint, modèle, persistance, test.
ComprendreExpliquer le trajet HTTP → base.
RepérerIdentifier middleware, N+1, pattern utile.
Le bon réflexe

Si tu bloques sur la syntaxe, cherche-la. Si tu bloques sur le trajet d'une donnée, suis un appel unique au débogueur depuis HTTP jusqu'à la base.
