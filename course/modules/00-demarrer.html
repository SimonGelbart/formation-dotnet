Démarrer et observer

Objectif : créer, lancer et déboguer un premier programme .NET sans chercher à tout comprendre du framework.

Pratiquer · CLI et débogageComprendre · SDK et runtime

Le trajet minimal

  1. Vérifier le SDK avec dotnet --info.
  2. Créer Sandbox en net10.0.
  3. Modifier Program.cs.
  4. Lancer avec dotnet run.
Console.WriteLine("Bonjour .NET");
À retenir

Le runtime exécute une application. Le SDK contient en plus les outils nécessaires pour la développer et la compiler.

Vérifier que j'ai compris

Compiler vérifie et transforme le code avant exécution. Pour observer une variable sans ajouter de Console.WriteLine, place un breakpoint et utilise le débogueur.
