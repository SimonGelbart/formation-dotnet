Une classe décrit, new crée

var product = new Product();
product.Name = "Clavier";
product.Price = 30m;

Console.WriteLine(product.TotalFor(2));

public class Product
{
    public string Name { get; set; } = "";
    public decimal Price { get; set; }

    public decimal TotalFor(int quantity)
    {
        return Price * quantity;
    }
}
Lecture guidée

Product décrit la forme et le comportement. new Product() crée une instance. Les propriétés portent les données ; la méthode calcule un résultat.

Le littéral 30m force un decimal, utilisé ici pour les prix.

Valeur présente

string name = "Clavier";

Valeur facultative

string? description = null;
