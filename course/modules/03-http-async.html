var builder = WebApplication.CreateBuilder(args);
builder.Services.AddControllers();

builder.Services.AddSingleton<IProductRepository, MemoryProductRepository>();

Task<T> joue le rôle d'une promesse

using var client = new HttpClient();
client.BaseAddress = new Uri("http://localhost:5080");
using var timeout = new CancellationTokenSource(TimeSpan.FromSeconds(5));

var products = await client.GetFromJsonAsync<List<ProductResponse>>(
    "/products", timeout.Token);
Ce que fait await

L'opération réseau peut suspendre la méthode sans monopoliser un thread pendant l'attente.

Le CancellationToken transmet une demande d'annulation aux opérations qui savent la respecter.

Deux attentes successives

await Delay(500) puis encore 500 ms ≈ 1000 ms.

WhenAll

Deux attentes indépendantes peuvent se chevaucher ≈ 500 ms. Cela ne prouve pas deux calculs CPU parallèles.
