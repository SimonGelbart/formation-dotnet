Manipuler un catalogue

Objectif : choisir une collection, filtrer, trier et projeter les produits avec LINQ.

Pratiquer · List, Dictionary, LINQComprendre · IEnumerable et exécution différée

filter

C#

Une requête peut rester différée

var cheap = products.Where(p => p.Price < 20m);
products.Add(new Product(4, "Câble", 5m));
Console.WriteLine(cheap.Count()); // 2

Where décrit ici une séquence. Count() la parcourt après l'ajout. Ajouter ToList() matérialise immédiatement le résultat.

Choix simple

Liste pour parcourir/ajouter, dictionnaire pour retrouver souvent par clé, HashSet pour l'unicité.
