Exposer le catalogue en HTTP

Objectif : créer un produit avec POST, récupérer son Location, puis le relire avec GET.

Pratiquer · GET, POST, DTO, validationComprendre · routage, DI, lifetimes

Une seule chaîne à suivre

HTTPControllerServiceRepositoryRéponse

ASP.NET Core transforme la route et le JSON en paramètres C# puis appelle l'action correspondante.

Le contrat HTTP reste explicite

[HttpPost]
public ActionResult<ProductResponse> Create(ProductRequest request)
{
    var product = _service.Create(request.Name, request.Price);
    return CreatedAtAction(nameof(GetById), new { id = product.Id }, ProductResponse.From(product));
}

Le Controller décide ici du statut 201. Le service ne connaît pas HTTP.

Lifetime à observer

Le repository mémoire est Singleton pour conserver les produits entre requêtes. Le service peut être Scoped.
