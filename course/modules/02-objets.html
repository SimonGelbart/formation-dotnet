Chapitre 02 · Fondations

Construire des objets cohérents

Objectif : empêcher qu'un produit puisse exister avec un nom vide ou un prix négatif.

Pratiquer · constructeur, encapsulationComprendre · valeur / référence

La règle vit dans l'objet

public void ChangePrice(decimal price)
{
    if (price < 0)
        throw new ArgumentOutOfRangeException(nameof(price));
    Price = price;
}

private set empêche le code extérieur de contourner cette méthode.

Type valeur

Copier un int copie sa valeur. Modifier la copie ne change pas l'original.

Type référence

Deux variables peuvent désigner le même objet. Modifier l'objet via l'une est visible via l'autre.

Expérience

Crée other = product, change le prix via other et observe product.Price. Tu verras la même instance.
