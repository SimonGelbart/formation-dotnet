Chapitre 09 · Qualité

Tester un comportement

Objectif : détecter une régression du prix historique ou un oubli de sauvegarde.

Pratiquer · test métier, fakeComprendre · unitaire vs intégration

Le test raconte une règle

[Fact]
public void OrderKeepsOriginalPrice()
{
    var product = new Product("Clavier", 30m);
    var order = new Order();
    order.AddItem(product, 2);
    product.Update("Clavier", 50m);
    Assert.Equal(60m, order.Total);
}

Pas de serveur ni de base : le test protège directement le comportement du domaine.

Domaine

Règles métier isolées.

Intégration

HTTP + DI + EF + SQLite en mémoire, avec relecture entre requêtes.

Fake ciblé

Le fake repository n'essaie pas d'imiter tout EF. Il simule juste assez pour vérifier que le service sauvegarde.
