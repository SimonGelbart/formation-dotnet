Un objet cohérent protège sa propre règle

public Product(string name, decimal price)
{
    if (string.IsNullOrWhiteSpace(name))
        throw new ArgumentException("Nom obligatoire", nameof(name));
    Name = name.Trim();
    ChangePrice(price);
}

public void ChangePrice(decimal price)
{
    if (price < 0)
        throw new ArgumentOutOfRangeException(nameof(price));
    Price = price;
}

La DI commence avant ASP.NET Core

public interface IProductCatalog
{
    IReadOnlyList<Product> GetAll();
}

public class CatalogService
{
    private readonly IProductCatalog _catalog;

    public CatalogService(IProductCatalog catalog)
    {
        _catalog = catalog;
    }

    public int Count() => _catalog.GetAll().Count;
}
Traduction

Le service reçoit ce dont il a besoin au lieu de construire lui-même une implémentation précise.

MemoryCatalog, EmptyCatalog ou un futur catalogue peuvent satisfaire le même contrat : c'est le polymorphisme utilisé par composition.
