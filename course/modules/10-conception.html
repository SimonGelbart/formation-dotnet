Chapitre 10 · Qualité

Faire évoluer la conception

Objectif : ajouter plusieurs calculs de livraison sans accumuler des conditions dans Checkout.

Pratiquer · StrategyComprendre · responsabilités, couplage, SOLID

Strategy = un algorithme interchangeable

public class Checkout
{
    private readonly IShippingStrategy _shipping;
    public Checkout(IShippingStrategy shipping) => _shipping = shipping;
    public decimal Total(decimal subtotal)
        => subtotal + _shipping.Calculate(subtotal);
}

Standard, Express ou FreeAboveThreshold partagent le même contrat sans modifier Checkout.

Ne pas appliquer les patterns mécaniquement

Une interface par classe ne garantit ni SRP ni DIP. Le repository produits existe parce qu'il sert un besoin pédagogique concret ; OrderService utilise directement EF pour montrer l'autre compromis.

Repérer les autres patterns

Factory choisit quoi construire. Adapter traduit un contrat externe. Decorator enveloppe un collaborateur pour ajouter un comportement.
